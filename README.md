# 化工设计专家工作库

这是一个独立的化工设计 Skill 产品：19个专业模块、分层知识库、设备规则和
标准事实数据库、计算脚本、流程反馈、CLI与MCP接口在同一仓库交付。使用者不必
知道或安装其他RAG工程、设备选型仓库或桌面应用。

它用于把设计要求逐步落实为可以解释、计算和核验的工程方案，覆盖工艺路线、
Aspen流程建模、分离与能量集成、设备校核、费用分析和资料检索。它既规定工作
顺序，也提供实际可调用的数据和程序；专业软件仍由合法安装的运行环境提供。

技能集采用分层结构。宏观设计层确定系统边界、设计基准和评价方法；专业工作流
组织具体任务；操作脚本负责输入、计算调度和结果读取；知识资料为判断与计算提供
可追溯的依据。各层分工独立，通过项目记录和明确的输入输出衔接。

例如，换热器的负荷和温差先进入面积计算，得到数值及公式链；如果有适用于
该设备的单机限制，反馈程序再判断是否需要分段，并列出压力、热态、循环和
下游结果中必须重算的部分。资料不足只影响依赖它的结论，不抹掉已经成立的
计算；一个型号、建议或收敛状态也不会被当成全流程通过。

## 工作流程

```text
项目资料与设计要求
        ↓
设计基准、系统边界与方案评价
        ↓
专业工作流：建模 / 分离 / 能量集成 / 设备 / 费用
        ↓
操作与计算工具 + 适用资料检索
        ↓
设备能力检查 → 有依据的工艺修改 → 模型复算与再次选型
        ↓
同版结果校核、工程记录与交付
```

过程资料、模拟文件和工程报告应保存在独立项目工作区，不写入技能目录。一个任务
选用一个主要工作流，再按需要调用操作、设备和资料模块。

知识检索按“系统判断—原理机制—计算方法—来源细节”下钻，可按自然语言或节点
ID查询。设备入口提供18项本地操作，涵盖字段发现、单台与批量计算、标准检索、
结果组织、设备表、PFD数据及受约束的模型辅助建议回放。连续请求共用驻留后台，
每个设备仍保留独立结果和错误状态。

## 安装与开始使用

推荐下载 [Releases](https://github.com/milklong888/chemical-engineering-skills/releases)
中的完整离线发行包，解压到可写目录，先校验文件，再按[使用手册](docs/使用手册.md)
安装。随包依赖锁定为 Windows AMD64 的 CPython 3.14 环境；目标电脑需已有该
Python 解释器。依赖从包内安装，不在运行时下载。

仓库内的`plugins/chemical-engineering-skills/`同时采用Codex插件目录结构。
它附带本地 stdio MCP 服务源码和离线依赖，但不附带 Aspen、EDR 或 SW6。
资料查询和确定性设备计算无需这些商业软件；实际模型操作仍须目标电脑已安装、
许可并注册对应产品。云端模型对话也不会因为本地工具离线而变成离线模型。

## 分发范围

公开包包含原有专业方法与脚本、原理/方法/操作节点、带来源和QA状态的结构化
设备标准事实、设备后端、MCP 封装、依赖安装包及工程说明。源构建与历史维护脚本
保留单独用途，不作为另一套自动运行的选型引擎。

不包含教材扫描原件和整页 OCR 正文、真实项目模型、私人案例账本、商业软件、
独立桌面GUI/选型器EXE或软件许可证。存在身份记录但正文尚待公开审查的节点，会明确标识，
不会算作可检索正文。数据库中的方法、厂家边界和待核项也不会被改成正式设计值。

资料维护也在本产品内完成。新增来源经逐节点审查，在独立候选目录重建知识记录
和索引；任务经验则须在使用者确认当前版本结束后，另行审查能否形成宏观原则
或数据规律。查询过程不会偷偷修改知识库，局部放宽的任务结果不进入共享学习。

模块具备的功能、执行依赖和验证边界以本版本文档及实际文件为准。文件完整性和
离线检查通过，不代替某个工程项目的模拟、设备设计或安全审查。

# 90 未知问题路由

| 问题 | 处理 |
| --- | --- |
| 找不到对应国标 | 查官方平台和项目采用的行业标准；若仅有设计/安全标准，整机标为非标/厂家定型 |
| 标准有适用范围但无型号语法 | 只引用型式、基本参数或设计要求，不生成型号 |
| 标准表与项目参数之间需要圆整 | 写明上靠/下靠/最近系列规则；无条文规则时保留人工决策，不自行取整 |
| 标准版本即将切换 | 保存当前和未来两个节点；按设计冻结日期和项目要求选择，禁止提前实施 |
| 旧型号看似合理但没有来源 | 进入 `legacy_unverified`，不因外观合理升级 |
| 厂家型号网上能搜到但曲线不全 | 只标 `vendor_candidate`，保存官方样本URL和缺失工作点 |
| 塔/容器/反应器没有统一型号 | 输出“工程定制/非标设备”+关键规格+设计标准，不强造代码 |
| EDR/SW6/Column Internals与标准系列冲突 | 分成当前软件分支和标准候选分支；重新运行同设备后再裁决 |
| 标准PDF为扫描件或OCR不稳 | 只到文件身份；渲染页图人工核表后才能升A2/A3 |
| 一个型号字符串含多个来源 | 对每个片段单独建证据；任一关键片段不明则整体不得定型 |

## 停机条件

以下任一情况出现时，不得继续写正式型号：

1. 工艺设备身份不明；
2. 标准适用范围未核对；
3. 型号片段含义无法解释；
4. 厂家工作点或标准查表行缺失；
5. 两个权威来源冲突且未裁决；
6. 设备属于工程定制但表格强制要求商品型号。

# 18 型号与规格尺寸标准路由

本节只回答“现有国标/行标是否真的规定型号或尺寸”。标准标题中出现“要求”“设计”“试验”，不等于它给出可采购商品型号。

## 已核到明确型号/标记/尺寸规则

| 对象 | 标准和条款 | 标准直接规定 | 怎么选 | 仍不能证明 |
| --- | --- | --- | --- | --- |
| 管壳式热交换器 | GB/T 151-2014，4.3、6.2、附录B | 3个结构字母；型号由结构型式、DN、管/壳程设计压力、公称面积、管长、管外径/材料、管/壳程数、管束等级组成；数据表B.1给选型输入 | 先用工艺数据和 EDR 定结构、面积、压降、管径/管长/程数，再按GB/T 151组成标准型号 | 型号字符串不证明传热、压降、振动和机械强度通过 |
| 固定管板式热交换器 | GB/T 28712.2-2023，第5章及相应表 | 型式和基本参数系列，包括DN/PN、管径、管长、程数、管距和基本面积入口 | 计算所需面积后上靠标准系列，并按实际温压/材料检查范围 | 其他结构换热器不得套用；仍需EDR/SW6 |
| 轴向吸入离心泵 | GB/T 5662-2013，第3章、4.1、4.4、表1–2和图2 | 三段数字标记：吸入口直径-排出口直径-叶轮名义直径；表给设计点性能与尺寸，图2给Q-H推荐范围 | 用项目Q-H点筛选标准规格，再核转速、效率、材料、密封和NPSH | 不直接给IS/IH/AY/ZDP等厂家系列；不证明厂家曲线和NPSHr通过；项目冻结仍生效 |
| 膜组件 | GB/T 20502-2006，第2章 | 型号由类别代号-型式代号-性能指标-有效膜面积-膜材质代号组成 | 按膜类别、板框/卷式/折叠/中空纤维/管式、特征性能、有效面积和材质组码 | 型号不证明在本项目工况下的通量、选择性、回收率、寿命和纯度保证 |
| 膜装置 | GB/T 20502-2006，第3章 | 型号由类别代号-组件型式代号-外形尺寸-产水(气)量组成 | 先由流程/厂家定膜类别、组件型式、外形尺寸和保证产量，再按标准组码 | 不证明模块数、级间组合、stage cut、产品纯度和厂家保证 |
| 钢制对焊管件 | GB/T 12459-2025，5.2、第6章和尺寸表；GB/T 13401-2025，第4章 | GB/T12459给弯头/三通/异径管/管帽等型式、DN/NPS、端部外径和壁厚系列；标志的公称尺寸/外径、材料等级、壁厚/管表号代表压力等级 | 按管道等级、DN、外径、壁厚、材料、无缝/焊接和管件型式查表；订单同时写两个标准版本 | 不自动确定管道DN/壁厚和材料；先有管道计算和管道等级 |
| PN系列缠绕式垫片 | GB/T 4622.1-2022，第4、5章和9.1 | 适用PN10–PN250、DN10–DN3000；给型式代号、金属/填充带材料代号、尺寸表和完整标记 | 按法兰密封面、DN、PN、介质/温度和材料相容性查型式/尺寸，组成“型式+材料+DN+PN+标准号”标记 | 平面/突面、榫槽面的型式选择仍需按介质、工况和法兰-螺栓载荷判定 |
| Class系列缠绕式垫片 | GB/T 4622.2-2022，第4、5章和9.1 | 适用Class150–Class1500、DN15–DN600；给型式代号、材料代号、尺寸表和完整标记 | 按配对Class法兰密封面、DN/NPS、Class、介质和材料查表组码 | 不证明连接系统在具体螺栓载荷下的密封性 |
| 压力容器封头部件 | GB/T 25198-2023，5.1–5.2 | 给HHA/EHA/EHB/THA/THB/SDH等类型代号，标记包含类型、直径、名义/最小成形厚度、材料和标准号 | 由容器内/外径基准、设计温压、成形厚度和材料定部件标记 | 只是封头部件标记，不是整台塔/反应器/罐型号 |

## 标准给型式/性能边界，不给统一商品型号

| 对象 | 标准结论 | 正式选型办法 |
| --- | --- | --- |
| 压力容器、反应器、分离器、承压罐 | GB/T 150.1–150.4-2024规定材料、设计、制造、检验和验收，不定义整机通用型号 | 按工艺容积/分离/反应要求定结构和尺寸，按容器计算/SW6定壁厚、开孔、支座等，一览表写“非标设计/按图制造” |
| 塔器 | NB/T 47041-2014和SH/T 3098-2011主要给塔式容器设计边界，不给整塔商品型号 | 用 Aspen/Column Internals/厂家定塔径、塔板/填料和段高，用机械计算定塔体；写型式+关键尺寸+按图制造 |
| 搅拌设备 | HG/T 20569-2013可给安装型式、数据表和桨型选择入口，不给完整成套搅拌机通用型号 | 按流变/混合任务、容器几何、功率、转速、轴系、密封和厂家数据定型 |
| 通风机 | GB/T 3235-2008规定基本型式、尺寸参数、推荐数和性能曲线表达，不给厂家商品型号 | 按流量-压力-效率点预选，再用厂家曲线和材料/转速/噪声数据定型 |
| 石油炼化透平压缩机 | GB/T 45820-2025要求明确正常点、额定点和唯一保证点，并规定性能保证，不给统一机型代码 | 用气体性质、流量、压比、保证点和调节范围编制询价数据表，由厂家给机型/map |
| 一般用汽轮机 | GB/T 28573-2012附录D给完整询价数据表，铭牌需标厂家规格/型号、额定功率/转速等，但不定义统一商品型号语法 | 用蒸汽工况、功率、转速、排汽条件和调速要求发厂家询价；工艺气体膨胀机不能自动套用 |
| 钢制阀门 | GB/T 12224-2015给PN/Class材料分组、压力-温度额定值、端部/阀杆/壳体要求，不给各阀型和厂家通用商品型号 | 先按功能选闸/截止/止回/球/蝶/调节/安全阀，再按专用产品标准、DN/PN/Class、材料、连接、Cv和厂家数据定型 |
| 工业管道 | GB/T 20801.1-2025给分类、材料、压力设计、直管/管件/法兰计算、制造安装、检验试验，不定义“管道型号” | 用Line List/P&ID、水力计算定DN，用压力设计/腐蚀余量定壁厚，用材料和应力分析定管道等级 |

| 容积式压缩机验收 | GB/T 3853-2017采标版权无官方全文 | 只作验收试验题录入口，不用它定压缩机型号 |

## 输出状态

- 标准真的给出标记/系列，但未做同设备计算：`标准规格候选`。
- 标准不给整机型号：`非标设计/按图制造`或`待厂家定型`。
- 官方正文缺失：`标准身份已核，正文/页表待补`。
- 只有计算/软件/厂家证据闭合后，才能写 `型号已确认`。

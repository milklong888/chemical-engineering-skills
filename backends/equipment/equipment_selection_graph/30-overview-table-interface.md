# 30 设备选型一览表输出接口

## 推荐列

| 列 | 来源 | 规则 |
| --- | --- | --- |
| 序号/工段/位号 | 当前项目设备映射 | 不从参考项目迁移 |
| 设备名称/作用 | 当前流程与Aspen连接 | 名称应反映真实工艺任务 |
| 设备族 | 图谱路由 | 与Aspen块类型分开保存 |
| 型式/结构 | 型号确定卡 | 可以在型号未定时先闭合 |
| 型号 | 型号确定卡 | 必须附状态；非标设备可写“工程定制，型号待施工图/厂家” |
| 型号状态 | 状态机 | 不得省略 |
| 关键规格 | 标准表、软件或厂家数据表 | 每个字段保留来源 |
| 操作条件 | 当前项目Aspen/文档 | 同设备、同工况 |
| 设计条件 | 设计条件表/SW6输入 | 未冻结则写待补，不用经验默认替代 |
| 材料 | 腐蚀审查/机械设计/厂家 | “Carbon Steel”等材料族不能替代国标牌号 |
| 数量/备用 | PFD、控制和可靠性策略 | A/B泵等需明确 |
| 标准依据 | 标准号+版本+页表 | 禁止只写“国标” |
| 软件/厂家依据 | 导出/数据表/曲线编号 | 必须同设备 |
| 证据等级 | A0-A4 | A3以下不写“已确定” |
| 待补证据 | 型号卡 | 具体到输入/报告/表页 |

## 写入规则

- `型号状态=custom_equipment_no_universal_model` 时，型号栏写“非标/工程定制”，规格栏必须完整。
- `standard_candidate` 必须在型号后加“（标准候选）”。
- `vendor_candidate` 必须写厂家名、样本版本和曲线缺口；没有厂家名不得保留商品型号。
- 同一位号存在两个冲突型号时，型号栏不得二选一；先进入冲突表并清空正式型号。
- 原表已有值但无证据时，来源应写“旧表原值—未验证”，不能写“保留即正确”。

## 生成前硬检查

1. 所有型号行都有型号确定卡；
2. 所有标准都有版本和状态；
3. 所有厂家型号都有厂家/样本/曲线；
4. 所有非标设备不强造商品型号；
5. 所有候选/正式状态在表中可见；
6. 当前项目工况与旧模板介质无污染。

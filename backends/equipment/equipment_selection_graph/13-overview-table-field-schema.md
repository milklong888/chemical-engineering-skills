# 13 设备选型一览表字段模式

本文件是后续生成设备选型一览表的固定结构。参考 Word 的章节与表头可复用；其他项目的介质、型号、尺寸、材料、数量和标准序号不得迁移。

## 文档组织

1. 封面、编制信息和目录。
2. 第1章“标准设备选型”：T01–T10。
3. 第2章“非标准设备选型”：T11–T14。
4. 第3章“管道、附件与阀门”：X01–X05。
5. 每张表后保留“采用标准及版本、计算/厂家证据索引、选型状态、待补资料”。

## 各表必填字段

| 分区 | 设备 | 必填参数 | 不得缺失的证据 |
| --- | --- | --- | --- |
| T01 | 泵 | 位号、名称、泵型、型号/候选标记、介质、流量 Q、扬程 H、操作温度、密度、黏度、轴功率、效率、转速、材料、密封、运行方式、备用方案、台数 | Q-H-η/BEP、允许运行区、NPSHa/NPSHr、叶轮直径与厂家曲线 |
| T02 | 压缩机 | 位号、名称、结构型式、型号状态、气体组成/MW/k/Z、进出口温压、实际/标准流量、压比、级数、转速、功率、效率、冷却、驱动、材料、台数 | 正常点、额定点、保证点、喘振/堵塞线和厂家 map |
| T03 | 液体透平 | 位号、名称、类型、型号状态、流量、工作水头/压降、进出口压力、转速、效率、回收功率、材料、台数 | Q-H/效率曲线、空化/NPSH、调节范围与厂家数据 |
| T04 | 气体透平/膨胀机 | 位号、名称、型式、型号状态、工质组成、流量、进出口温压、焓降、转速、效率、功率、材料、台数 | 厂家性能图、转速/功率保证和超速/振动边界 |
| T05 | 标准换热器 | 位号、名称、结构代号、标准型号、换热负荷、传热面积、两侧操作/设计温压、允许压降、壳径 DN、公称压力、管径、管长、管数、管/壳程数、材料、数量 | 标准查表链 + 同设备 EDR 热工/水力 + 机械设计 |
| T06 | 储罐 | 位号、名称、常压/承压、立/卧式、顶盖型式、公称/有效容积、直径×高度、设计温压、介质、材料、液位、装填系数、保护/保温、数量 | 库存天数/时间、氮封、呼吸、泄放、消防、抗震、基础和机械计算 |
| T07 | 回流罐 | 位号、名称、立/卧式、公称/有效容积、直径×长度、设计温压、介质、材料、液位、保温、数量 | 塔顶冷凝量、停留时间、回流/馏出缓冲容积和机械计算 |
| T08 | 缓冲罐 | 位号、名称、型式、公称/有效容积、直径×长度、设计温压、介质、材料、液位、保温、数量 | 流量波动、缓冲时间、高低液位和机械计算 |
| T09 | 其他罐/工艺容器 | 位号、名称、工艺作用、型式、容积、尺寸、设计温压、介质、材料、保温、数量 | 停留/分相/汽液平衡依据和机械计算 |
| T10 | 静态混合器 | 位号、名称、型式、型号状态、管径、元件型式/数量、长度、设计温压、介质、流量、材料、数量 | Re/流态、压降、混合均匀度、堵塞/清洗边界和厂家数据 |
| T11 | 塔器 | 位号、名称、板式/填料、塔径、各段高度、总高、塔板/填料与内件、设计温压、封头、壳体/内件材料、保温/保护、数量 | 塔水力学/液泛/压降、Column Internals/内件厂家和机械计算 |
| T12 | 反应器 | 位号、名称、反应器型式、工作容积/床层、直径×高度、设计温压、封头、壳体/反应管/夹套/内件材料、列管数、搅拌型式/功率、数量 | 动力学冻结、停留时间、传热、压降、搅拌和机械计算 |
| T13 | 气液分离器 | 位号、名称、立/卧式、除沫结构、气液负荷、容积、直径×高度/长度、设计温压、壁厚、材料、进口/气出口/液出口接管、数量 | 允许夹带/液滴粒径、Souders-Brown/沉降、液体停留、液位、除沫压降和机械计算 |
| T14 | 非标/其他换热器 | 位号、名称、结构型式、按图制造编号/厂家型号状态、热负荷、面积、两侧温压/压降、板片/管束参数、材料、数量 | 同设备 EDR/厂家热工性能和机械计算 |
| X01 | 工业管道 | 管线号、起终点、介质/相态、流量、操作/设计温压、密度/黏度、DN、外径×壁厚/系列、腐蚀余量、材料牌号、管道等级、保温/伴热 | 水力计算、压力壁厚、应力分析、支吊架、试压和无损检测 |
| X02 | 管件 | 管线号、类型/代号、DN/NPS、端部外径、壁厚/管表号、材料等级、无缝/焊接、连接、数量、标准号 | 与所在管道等级、外径和壁厚一致 |
| X03 | 法兰 | 管线/接管号、DN/NPS、PN/Class、法兰型式、密封面、材料、配管外径/壁厚、紧固件、数量、标准号 | 压力-温度等级、配管和垫片匹配 |
| X04 | 垫片 | 配对法兰、型式代号、DN/NPS、PN/Class、密封元件/内环/定位环/填充带材料、标记、数量 | 介质相容性、温压、密封面、螺栓-法兰载荷和尺寸表 |
| X05 | 阀门 | 位号/管线号、功能、阀型、DN/NPS、PN/Class、压力-温度等级、Cv、正常/最大压差、阀体/内件/阀座材料、端连接、泄漏等级、执行机构、失效位、数量 | 工况 Cv/可调比、闪蒸/空化/噪声、阀型产品标准和厂家数据 |

## 统一补充列

每张表末尾统一增加：`采用标准及版本`、`型号/规格状态`、`计算书/软件/厂家证据号`、`待补资料`。

非标设备没有通用商品型号时，正式写法为“非标设计/按图制造”，不留假型号。

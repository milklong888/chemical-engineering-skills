# 21 管线确定卡

每条管线至少记录：

| 组 | 必填字段 |
| --- | --- |
| 身份 | 管线号、工段、起点、终点、介质、相态 |
| 工况 | 流量、操作/设计温度压力、密度、黏度、腐蚀/冲蚀/固含量 |
| 水力 | 允许流速与压降依据、计算内径、选定 DN、实际流速/压降 |
| 机械 | 外径、壁厚或系列、腐蚀余量、材料牌号、制造方式、管道等级 |
| 连接 | 管件、法兰 PN/Class、密封面、垫片、紧固件、连接方式 |
| 阀门 | 功能、阀型、DN/PN/Class、Cv/压差、材料、泄漏等级、执行机构、失效位 |
| 外部 | 保温、伴热、涂层、支吊架、应力分析、试压、无损检测状态 |
| 证据 | 每字段的来源、`reuse_class`、A0–A4 证据等级、补证项 |

缺少管道设计规范或管道等级时，只允许输出 `unresolved/type_selected`，不允许写“壁厚已验证”或“阀门型号已定”。

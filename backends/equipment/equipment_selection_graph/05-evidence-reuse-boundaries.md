# 05 证据复用边界

| 分类 | 允许 | 禁止 |
| --- | --- | --- |
| `direct_reuse` | 同版本标准正文明确给出的范围、标记、离散系列、表值 | 越出适用范围；由标准标题反推商品型号 |
| `method_only` | 公式、审查流程、空白表头、字段结构 | 迁移例题数值、材料、介质和型号 |
| `software_boundary` | 同设备 Aspen/EDR/SW6/Column Internals/水力/应力计算回读 | 用不同位号或不同工况软件结果替代 |
| `vendor_boundary` | 同位号厂家曲线、性能图、Cv、数据表和保证值 | 只凭系列名或旧报告型号定型 |
| `forbidden_transfer` | 仅能作污染警示/负例 | 参考项目管号、介质、尺寸、材料、设备型号、数量和厂家数据 |

复用分类落到具体声明或边，不给整份文件简单贴标签。同一标准可同时包含 `direct_reuse` 条文和 `method_only` 附录。

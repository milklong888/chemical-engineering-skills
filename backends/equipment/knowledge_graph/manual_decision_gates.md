# Manual Decision Gates

## Gate 1: 设备身份

- 同一位号同一文档版本：可复算数值。
- 同设备族不同位号：只迁移方法。
- 不同设备族：只能借鉴审计流程。

## Gate 2: 公式适用性

人工确认：相态、单位、设计目标、规范适用范围、参数来源、最终证据边界。

## Gate 3: 参数默认值

人工设定默认值必须写：默认值、单位、来源、用途、为何可用。不能空写待定，也不能无来源硬填。

## Gate 3A: 标准复用

新增标准/手册/教材进入参数表前，人工必须判定：

- 是标准查表值、方法参考、软件边界、厂家边界，还是禁止迁移值。
- 是否同版本、同输入、同单位、同设备族。
- 是否已有条文页或标准表页核验。
- 是否会越过 EDR/SW6/Column Internals/厂家/动力学冻结链边界。

未满足时保留现有报告默认值，并标为 `method_only`、`software_boundary` 或 `review`。

## Gate 4: 对不上审查

按顺序排查：抽取错误 -> 单位错误 -> 公式错误 -> 参数来源冲突 -> 文档表格错误 -> 人工假设不适用。

## Gate 5: 升级证据

只有补齐软件/厂家/文献导出后，C/D/E类才能升级。不得因为脚本能跑就升级。

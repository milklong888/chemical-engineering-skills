# Evidence Boundary Nodes

| 等级 | 名称 | 可声明内容 | 不可声明内容 |
| --- | --- | --- | --- |
| A | 公式复算通过 | 明确公式/输入/文档值能被脚本重复 | 不代表软件/厂家正式校核 |
| B | 复算到选型前步骤 | 表值、条件、圆整前后逻辑可解释 | 不代表最终机械/软件通过 |
| C | 需外部软件证据 | EDR/SW6/Column Internals提供正式证据 | 脚本不能替代内部模型 |
| D | 动力学暂定 | 可审计单位换算或拟合 | 不得作为Aspen正式动力学卡片 |
| E | 象征性/目录选型 | 型号/尺寸已有汇总 | 不得宣称严格校核 |

## 标准证据边界

| 标准证据 | 可声明内容 | 不可声明内容 |
| --- | --- | --- |
| 标准文件名/标准号可确认 | 可作为来源节点和查表入口 | 不代表条文数值已核验 |
| 标准表页已人工核验 | 可支持标准尺寸/型式来源 | 不替代强度、软件或厂家校核 |
| 手册/教材/课程设计 | 可支持方法和术语 | 示例值、案例工况、经验默认值不得迁移 |
| 报告值与标准入口逻辑匹配 | 可说明当前参数来源合理 | 不升级为完整工程证据 |

## 软件边界

- `EDR`: 面积、U、Re、压降、推荐结构、Rating/Checking。
- `SW6`: 裙座、管板、法兰、开孔补强、地脚螺栓、整体强度。
- `Column Internals`: 塔径、填料数据库、液泛、能力因子、压降。
- `Vendor`: 泵/压缩机/膜/填料/储罐系列曲线和型号适用性。
- `Kinetics`: 原始文献方程、单位、rate basis、concentration basis、Aspen卡片和导出验证。

## EDR 升级门槛

1. `EDR file present`：只有文件身份，不代表运行或完成。
2. `EDR calculation accepted`：同设备 `.EDR` 的 `TascMsg` 无未解决的输入错误/运行失败，结果物理合理。
3. `Aspen binding accepted`：重开后仍为 `TASCPLUS-RIG` 且报告/输出证明 EDR 执行。
4. `Aspen delivery accepted`：最终复制文件 Required Input 完整、Run Status 全零、原始历史无实际问题行，流程与产品门槛保持。
5. `engineering design accepted`：面积裕量、压降、速度、振动、物性范围和材料均闭合。
6. `mechanical/vendor accepted`：SW6、厂家图纸、制造规范和性能保证闭合。

第 4 级通过不能替代第 5-6 级。尤其是负面积裕量、物性曲线超范围或材料待定，必须继续写为工程待闭合项。

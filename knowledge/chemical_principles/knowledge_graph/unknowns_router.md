# 化工原理未知问题路由

## 先判断问题层级

### 思想、常识或整体判断

例如：

- 为什么模拟收敛仍可能不合理？
- 怎样判断一个单元操作或流程是否“好”？
- 强化传热/传质为什么不能只追求系数最大？
- 平衡与速率在设备设计中分别决定什么？

先读 L3 概念节点，再按需要下钻 L2/L1/L0。

### 物理机制

例如层流/湍流、边界层、相平衡、扩散、过滤、干燥机理。先定位章节
L2 节点；若涉及跨单元关系，同时回读关联 L3 节点。

### 计算方法

先冻结系统边界、单位/基准、相态、稳态/非稳态和所需结果，再进入 L1
方法节点。只有在确定方法与适用域后才读取 L0 公式和数值。

### 原文、公式、图表或数字

直接定位章节和 PDF 页，但必须返回：

`source_id + PDF page + source SHA256 + OCR/视觉核对状态`

公式、上下标、图表点和数值在视觉核对前不得标为直接可靠。

页级检索入口：

```text
python chemical_principles_knowledge\scripts\query_textbook_evidence.py <terms>
```

## 无命中时

1. 查章节主题、同义词和上下位概念；
2. 查页 OCR 与图表标题候选；
3. 做单位/量纲、守恒、极限和趋势推导；
4. 仍缺时只阻断该项，并说明最小缺口；
5. 不得用项目案例或预训练记忆填入教材原文。

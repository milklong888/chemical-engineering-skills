# 化工原理知识图谱错误记忆

## CPR-ERR-001 — 页级细节淹没思想与原理层

- `scope`: 化工原理教材数字化、知识图谱与 RAG
- `trigger`: 扫描教材形成大量 OCR 页块、公式、表格和例题
- `mistaken_behavior`: 将全部内容平铺入库，用相似度直接返回细节，却没有系统观、物理观、方法选择和设计判断的上层结构
- `invariant`: 图谱必须自上而下分为思想/系统原则、核心原理与机制、方法/推导、定量细节与页级来源；先在最高充分层回答，再向下取证或计算
- `detector`: 宏观问题首先命中思想节点；原理问题命中机制节点；公式和数值问题才下钻到细节/原页。所有上层节点必须有下行来源锚点，例题数值不得成为通用默认值
- `repair`: 建立显式层级元数据、上下行边、分层路由和正反检索测试；未获来源支撑的思想总结保留为候选或隔离
- `evidence`: 用户于 2026-07-24 明确要求“层级区分，细节的下方，思想观念的提升”
- `evidence_update`: 2026-09-09 用户再次要求 RAG 作为常识图谱有机进入现有 Skill；设备反馈与思想层分工而不是把程序参数当作通用原理

- `status`: verified_by_user
- `priority`: P0

# 设备知识治理路由

实际设备节点、公式规则、数据和当前确定性计算由 [设备后台](../../backends/equipment/README.md) 承担。本目录仅连接错误 owner 与待审入口，不复制第二份数据或激活旧 2.3 计算器。

调用顺序：当前项目来源及验收合同 → [错误 owner](00_ERROR_MEMORY.md) → 设备后台当前方法/数据 → 同设备计算与证据 → 项目审计。新资料留在 [NEW_KNOWLEDGE.md](NEW_KNOWLEDGE.md) 的待审流程，不自动进入默认检索。

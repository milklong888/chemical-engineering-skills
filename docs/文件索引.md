# 文件索引

选择专业先查[任务登记](../plugins/chemical-engineering-skills/skills/chemical-engineering-expert/references/ACTIVE_ASSET_REGISTRY.md)；
下一步或证据未知时查[决策树](../plugins/chemical-engineering-skills/skills/chemical-engineering-expert/references/TASK_DECISION_TREES.md)。
维护组织、执行记录或论文机制时查[维护入口](../plugins/chemical-engineering-skills/skills/chemical-engineering-expert/references/MAINTENANCE_TOOLS.md)。

本索引按工程工作顺序定位当前产品实际附带的文件。每个专业节先说明怎样使用该组文件，再逐项列出入口、方法、脚本和证据边界。想先理解完整工作流与模块交接，请读[模块说明](模块说明.md)；需要找到具体实现和输入合同，再回到本页。

文件名与功能不是同一回事：`SKILL.md` 是任务入口，`references` 是按需阅读的方法或合同，`scripts` 中既有完整工具也有接入模板，`examples` 与测试夹具只用于说明和回归。明确标为合成、占位或外部资料合同的内容，不能当作真实工程数据或已经运行的软件证据。

本页保留专业技能及原工程文件的逐项说明。恢复的知识正文、设备后台、离线依赖、原始维护源码和新增连接/测试文件，完整列在 [新增后台文件索引](新增后台文件索引.md)。文件集合随封版更新，不沿用早期版本的固定总数；实际字节与准确集合以最终 `RELEASE_MANIFEST.json`、`SHA256SUMS.txt` 及发布校验结果为准。版本控制内部目录和运行缓存不在索引内。

## 使用约定

所有链接均指向本仓库文件，技能节中的显示路径相对于对应技能目录。执行脚本前先读取该模块入口及相关依赖说明：离线检查一般只需 Python 和注明的库，真实 Aspen/EDR/SW6 操作还需要适用软件、许可、版本及当前任务授权。任何一次程序正常退出，都不能自动替代物理合理性、产品要求和同文件运行证据。

## 三、分段流程边界

模块目录：`aspen-two-section-flowsheet`。

先用入口确定工程段及跨段流股义务，再选择独立段、单元岛或接回方式。需要生成输入时读取 profile 合同，将当前项目组分、分子量、卡片和单位显式提供给保留的生成函数；输出交给公共操作层另行授权运行。原函数保全映射与只读审计文本用于核查迁移，不是另一条自动运行路径。

## 封版时生成的清单

`RELEASE_MANIFEST.json` 记录实际发布文件、字节与摘要，`SHA256SUMS.txt` 提供对应校验和。它们在封版时按实际目录生成，不作为手工编写的设计资料；取得发布包后先用发布校验器核对。随包的知识记录、数值向量和设备数据库属于公开资产，见 [新增后台文件索引](新增后台文件索引.md)。ZIP容器、运行缓存及使用者随后生成的模型、索引和报告不作为仓库源文件逐项列入。

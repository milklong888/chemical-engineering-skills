# 外部资料与软件

## 1. 软件依赖

| 依赖 | 用途 | 配置及验证要求 |
| --- | --- | --- |
| CPython 3.14 Windows AMD64 | 本版本完整离线依赖目标。 | 解释器由目标电脑提供，依赖由包内固定轮子安装；不承诺跨Python ABI可用。 |
| NumPy | 本地向量索引构建和查询。 | 2.4.6轮子与独立锁随包；基础词项查询不依赖它。 |
| Windows及相应COM适配 | 自动化调用本机工程软件。 | 位数、软件注册和Python环境应匹配；注册表命中不代表运行和许可证检查已通过。 |
| Aspen Plus | 流程模拟、物性、设备模型、收敛与导出。 | 使用者自行安装并获得许可；具体版本按项目冻结。 |
| Aspen EDR/BJAC | 换热器热工设计和校核。 | 需要对应程序、接口及同设备计算结果，不以普通HeatX结果代替。 |
| SW6 | 适用范围内的设备强度计算及计算书。 | 需要本机合法软件、结构输入和正式计算结果。 |
| 报告排版工具 | 按专业模块制作需要的文档或图表。 | 相应模块另列依赖，不由本包统一安装办公软件。 |

本发行包不携带商业程序、许可证或许可证服务配置。它携带本地MCP封装及71个
固定依赖轮子（70个原运行依赖加NumPy扩展），保留许可证正文与身份。工具默认
不启动GUI，知识/设备接口不启动Aspen。MCP宿主须指定本地Python和脚本路径；
没有宿主时直接运行同一个CLI，不需要另外建设服务平台。

## 2. 工程资料

正式计算依据由项目提供，包括任务书、实验或文献数据、适用标准、设备手册、
厂家资料、已有模型及原始运行记录。每份资料应保留来源、版本和适用范围。

教材和软件帮助用于理解方法、字段及适用条件，不能替代本项目的数值依据。
真实项目数据、设备报价和原始模型不包含在本公开包内。

## 3. 随包知识与索引

本产品内部完成来源定位、分层检索、节点下钻和候选版本构建。原理、方法、
操作节点及实际哈希向量索引一并随包，不需要下载其他RAG仓库或访问远端服务。
它使用资料索引定位原始依据。宏观问题先读取原则和方法节点，需要计算
时再查看公式、表格和原始页。相似度只用于排序，不改变资料的项目范围、版本
及证据等级。正式引用应回到原始来源或同案结果核对。

工作区图谱的路径由本地路由记录维护。接入新资料时同时记录资产名称、位置、
来源、许可边界、版本和是否参与默认检索。不要将账号文件、整个用户目录或
未经筛选的项目历史作为索引输入。

## 4. 随包设备计算与数据

设备公式、候选匹配、规则、数据和证据审查程序在 `backends/equipment/` 内。
统一入口开放18项纯本地操作，批量调用复用同一个驻留后台；不要求安装独立
选型软件。`equipment-design-app`模块负责程序调用和结果解释，工艺设计层
判断是否采纳调整方案。代码及数据的来源身份见[来源与许可](来源与许可.md)。

每次计算记录程序版本、数据包版本、输入单位和输出结构。设备程序返回的
候选不是最终工程验收结论；目录数据、厂家曲线和软件计算结果按各自来源使用。
本包提供经审查的结构化标准事实投影；不提供私人项目值、默认设备报价或厂家
保证值。原资料缺口与尚未验证状态保留，不将数据库体积当作完整性指标。

## 5. 可选本地资产

源教材、商业帮助、标准图谱、项目案例、成本数据和历史试算可作为本地资产。
它们不因本技能集发布而变为公共资料。项目专用扩展保持独立，不并入通用入口；
例如特定openLCA项目的设备费用批处理不属于本发行范围。

公开仓库未设置覆盖所有第三方内容的统一许可。取得和分发外部软件、文献、
标准及数据时，应分别遵循其使用条件。公开版的文件清单只说明本包实际包含的
文件，不对未附带的外部材料作授权承诺。

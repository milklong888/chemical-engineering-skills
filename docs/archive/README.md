## 封存原则

下列 13 份文件按原字节保存，来源提交为
`06306b58f99faf93752b1d6cbe2c2a3688db0022`。原路径、归档路径及 SHA256
逐项写入 [archive_manifest.json](archive_manifest.json)。原提交与旧发行包均保留，
没有删除或重写历史。

归档文字中的版本号、工具数、节点数、测试数和操作入口仅代表其当时状态。
其中已被替代的说明不能与当前规则并列使用。归档文件保留原有相对链接，
需要沿旧链接阅读时请打开[原提交中的 docs 目录](https://github.com/milklong888/chemical-engineering-skills/tree/06306b58f99faf93752b1d6cbe2c2a3688db0022/docs)，不要将旧路径理解为现行入口。

## 与运行的隔离

本目录是发行包中的历史文档区，不位于 `plugins/.../skills`、`knowledge`、
`backends` 或 `tools` 下。安装器不将它安装为活动 Skill 或运行后台，知识检索
不扫描本目录。历史材料只经本页明确进入，不作为当前能力和通过状态的证据。

# 0.4.11 维护记录

本版在 0.4.10 工作流程上整理开源授权、使用说明和历史入口，没有替换设备算法、
知识正文、原有脚本或商业软件接口。完整包仍保留 19 个 Skill、17 类设备后台、
知识正文和索引、标准数据库、原 Aspen MCP 源码及 71 个离线依赖轮子。

## 本次变化

1. 自研代码、脚本、Skill 指令和说明文字正式采用 MIT。第三方许可、引用资料
   与数据权利单列，不用根许可证替代其原有条件。
2. 核对 71 个依赖包的元数据、151 个实际许可／通知文件和 fastmcp-slim 的
   外置许可。随包保留原字节，补充可核对的许可清单；安装手册明确说明这些
   许可文件应与发行包保留，单独再分发安装目录时须一并附带。
3. 现行说明统一专家 MCP 为 10 项、知识记录为 6,942 条，其中 6,919 条进入
   768 维哈希特征索引，23 条待核记录不进入向量检索。旧版统计不改写。
4. 工作原理说明补齐五份独立源审查、实际骨架运行和三份导出复核、模块末设备
   检查与接回后的整厂复核，并澄清 MCP 和原生工具建卡的实际能力边界。
5. 13 份旧说明与验证文件按原字节归档，原路径与 SHA256 登记在归档清单中。
   历史区不进入活动 Skill 和默认知识检索，旧版本标签与下载包继续保留。
6. 补充许可、归档和工具路由契约测试；更新过时的 MCP 工具枚举，并实际调用
   `workflow_lookup` 检查 19 个工作流入口。

## 版本与证据

本次文档基线是主分支提交 `06306b58f99faf93752b1d6cbe2c2a3688db0022`。
0.4.10 的正式标签和下载 ZIP 保持原样。0.4.11 使用独立标签、发行清单、ZIP
和校验文件，不拿修改后的主分支清单去核验旧下载包。

本轮不启动真实 Aspen、EDR 或 SW6 工程，不新增工程通过声明。程序测试只证明
其列明的接口与行为；实际项目仍执行[严格验收](验证说明.md#真实工程验收)。

# 0.4.9 分库查询修复

指定 `--corpus chemical_principles` 时，旧查询仍先用全部 6942 条记录挑选中文片段，再过滤答案。域外稀有片段可能占用有限词项，导致分库里已有的内容漏检。

本版让自然查询的词项统计先遵守分库与正文准入范围。向量查询先验证既有索引，再按实际向量记录的分库、准入和范围条件选择词项；后续结果过滤继续保留。精确 ID 查询维持原有评分、身份与待核空正文行为。

## 实际核验

两条已冻结的长句分别询问汽液平衡数据一致性、阀门与透平出口的能量约束。在 `chemical_principles` 范围内，修复后字面与哈希向量查询均能在前 5 项找到对应知识。这个同例对照用于验证已定位的缺陷，不是盲测或通用准确率。

原有 11 项查询回归加 2 项分库召回/词项范围检查，共 13 项在独立候选目录运行通过。主线还核验了 6 条合成记录的分库、缺字段、无正文和未准入过滤，并确认带问题文字的待核精确 ID 查询与旧版完整返回相同。主线审查了代码差异和实际产物；不将这些检查称为第二位代理的独立代码审查。

正式整合后，冻结知识文件运行来源维护测试，25 项全部通过（295.517 秒）。此组检查覆盖候选构建、来源准入、索引与路径边界；不等同于逐条工程内容复核。

## 不变项与限制

四批新增的 69 个完整知识块、全库 6942 条记录、来源、关系以及 6919×768 哈希矩阵均不变；没有重新摘要或重建向量，没有启用学习式 embedding。原始 PDF 和私人审计资料不公开。

本次修复分库词项统计，不承诺默认 `all` 查询或任意长句都能命中。问题范围明确时先选择相应分库，仍缺依据时再跨库查找；必要时使用主题词或精确 ID 取全文。检索结果仍是来源知识，不是当前项目参数或工程验收结论。

# 来源与许可

本产品是独立发行的化工设计工具与知识体系。安装、查询、设备计算、反馈和
维护入口都在本仓库内；下列项目用于说明来源，不是运行依赖或安装前置条件。

不等于其原文获得了 MIT 授权。[第三方及数据范围](../THIRD_PARTY_NOTICES.md)

## 工程来源与身份

- 设备后台以 [equipment-design-selector](https://github.com/milklong888/equipment-design-selector)
  的 `e3a5f1bffd1889b8c70ae0b1f3343f7fccbeea20` 为来源基准。包内保留
  计算、规则和协议的来源清单，并对公开数据投影与源数据身份分别登记。
- 知识组织与准入工作参考 [chemical-engineering-rag-kg](https://github.com/milklong888/chemical-engineering-rag-kg)
  的来源树、抽象层和语义单元组织方法。本产品实际正文、节点状态和向量内容
  以 `knowledge/manifest.json` 及逐源保全记录为准，不使用其他工程的统计数
  代表本产品的覆盖范围。
- Aspen MCP源码位于 `vendor/aspen-mcp-toolkit/`，保留上游身份及许可证。
  离线依赖由包内锁文件和逐文件哈希限定，各依赖按各自许可证使用。

## 本产品保留的证据

设备源码清单在 `backends/equipment/app/source_code_manifest.json`；实际运行
数据在 `backends/equipment/runtime_asset_manifest.json`；数据库投影的身份和
来源关系在 `backends/equipment/data/standard_facts_manifest.json`。知识库的
来源记录与保全差异随 `knowledge/` 提供。完整发行文件清单由根目录
`RELEASE_MANIFEST.json` 封存。

历史身份记录用于追溯，不把旧实现的路径和接口说明当成本产品当前用法。
日常操作按[使用手册](使用手册.md)、[模块说明](模块说明.md)及实际能力声明执行。

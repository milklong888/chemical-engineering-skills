# 运行层与知识文件索引

本附页与 [专业文件索引](文件索引.md) 共同覆盖当前仓库的可发布文件。本页按用途说明知识、后台、桥接、依赖和源码维护资产，并区分运行工具、资料重建工具及工程证据。

用途按模块边界解释，文件身份按实际清单校验。`.git`、运行缓存以及用户今后生成的报告/模型不在此索引内；随包向量与标准数据库则明确属于公开资产。封版可能更新清单字节，因此不在手册硬写仍会变化的全仓库总数。

阅读顺序：先定位问题需要的知识层或设备职责，再读输入合同，最后找计算/运行实现与相应验证。源代码保全、离线接口通过和真实化工工程通过是三种不同结论。

## 如何核对完整性

本附页列出新增的每个非wheel文件，原页覆盖既有专业文件。wheel逐项表直接见主依赖锁与NumPy扩展锁；最终发布文件及SHA以根目录发布清单为准。运行 `python tools/verify_release.py --root .` 检查实际文件集合，之后再按使用手册做隔离安装和所需模块验证。对未随包原件、真实BKP、EDR/SW6/厂家证据的缺口，保持明确边界，不用合成测试顶替。

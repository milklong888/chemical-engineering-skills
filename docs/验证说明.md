## 1. 发布检查

发布检查针对实际发行目录，包括文件清单与哈希、文本编码、插件与技能入口、
安装定位标记、被分发文件的内容边界、说明文档链接以及压缩包回读。

文件变更后应重新生成发行清单，不沿用旧文件的校验值。安装前核对整个包；
安装后的路径定位变化由安装记录管理，原发行包保持不变。

## 2. 离线验证

离线测试可以验证文本解析、输入分类、候选边界、文件身份、目录保护、重复
安装、失败状态和逻辑计算。使用合成输入的测试明确标识其性质，不把示例输出
描述为真实Aspen结果。

本包中的INP示例只用于说明输入结构或检查逻辑；它们不是用户工程模型，也不
作为已通过项目验收的流程文件。

实际发布验证结果记录于发行清单和对应版本的发布说明。软件接口测试须说明
是否实际启动了程序、使用哪个版本，以及输入与输出文件的身份。

## 3. 工程验收

工程项目另行验证反应与物性方法、物料和能量衡算、循环、产品、设备、操作及
安全条件。软件解析器或安装测试通过不能代替这些工作。

Aspen的错误汇总表按经核对的版本结构解释，所有要求的错误及警告计数为零；
同时检查本次完整运行历史，不以单独成功短语替代日志证据。最终文件复开运行
及项目产品要求按专业工作流执行。

EDR、塔内件、SW6和厂家资料的结果分别保留其适用设备、工况、版本和来源。
初筛类型、建议参数、严格计算和正式交付分开标识。

## 4. 复现边界

同一文件哈希只能证明文件相同。计算复现还依赖软件版本、物性数据库、输入
基准、外部数据、求解设置和运行条件。缺少其中关键条件时，应说明能复现的
范围，不把未执行的检查列为通过。

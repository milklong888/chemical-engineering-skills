# 0.4.8 知识库更新

## 新增内容与处理程度

四批资料按实际用途筛选，合计新增69个完整知识块：反应过程14、精馏动态控制与特殊分离13、热力学与相平衡25、换热网络与蒸汽动力系统17。先比较已有覆盖，再回读有用主题；重复内容、无独立用途的展开、旧按钮步骤和例题数字不单独入库。标准是能无歧义复述含义和必要条件，不是逐页转写或逐符号拆分。

当前知识库有6942条记录，6919条具备检索资格并形成768维 float32 哈希向量。全部新增释义、关联节点、来源采纳记录和索引均随完整包提供。每批主题与实际跳过范围见[新增知识说明](../knowledge/intake/README.md)。

## 查询与重复展示

本次只改查询适配层：增加库内可观察的中文片段匹配，以内容关联度配合有限层级偏好排序，避免弱相关泛原则挤占直接答案。原向量生成算法、来源准入和项目权威边界不变。

整库检查发现120个完全同文组，涉及384个ID。查询将同文内容展示一次，同时列出不同ID、标题、来源和适用范围；不按相似度删除或重写知识。纯章节标题不再单独作为自然问答结果，精确ID仍可回读；短公式和短方法不按长度一刀切。

## 公开与核验边界

公开来源编号、原文件哈希和精确物理页锚；原始PDF、整页转写、私人路径和未审稿不公开。所供能量资料之外的线上附录未访问，不计为已处理。新增知识是来源支持的通用解释，不是当前项目参数，也不代表 Aspen、EDR、SW6 或工程方案已经验证。

原有23条待核正文继续隔离，未因本次更新而进入向量矩阵。既有记录不重编号、不用短摘要替换；精确ID和来源仍可追溯。本轮没有执行整个工作区或设备选型目录的旧文件清理。

## 贡献与读取

新增[知识贡献与读取准则](../knowledge/CONTRIBUTING.md)，说明实用性筛选、完整知识块、语义去重、来源不清的待核处理、独立审核和发布边界。读者先取足以回答问题的完整主题，必要时沿精确关联ID下钻；片段不够时取全文，不凭检索片段补猜。

检索仍是本地、只读、确定性的哈希与字面定位，不调用学习式 embedding 服务、不下载模型、不启动商业软件。

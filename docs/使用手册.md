# 使用手册

## 1. 用途与工作范围

本技能集用于组织化工设计任务，并提供相应的操作方法和检查工具。它适用于已有
设计资料、计算目标或模拟文件的工作环境，主要处理以下工作：

- 确定设计基准，检查工艺路线、物流去向、能量品位、压力层级和循环结构。
- 将工艺要求转为Aspen组分、物性、设备、物流和控制规格，组织分段建模与整合。
- 处理精馏、热泵改造、换热设备、压力拓扑及其他专业计算任务。
- 核对模拟结果、设备参数、数据来源、工程报告与交付文件之间的一致性。
- 检索本地资料，维护可追溯的计算依据和经审查的方法候选。

技能文件规定工作方法，脚本执行具体操作。Aspen、EDR、SW6、设备选型器和
知识资料属于独立依赖，不因加载技能而自动获得。完整依赖见
[外部资料与软件](外部依赖.md)。

## 2. 目录及职责

| 目录 | 职责 |
| --- | --- |
| `plugins/chemical-engineering-skills/skills/` | 专业技能。每个模块有独立`SKILL.md`入口及按需读取的参考文件。 |
| `plugins/chemical-engineering-skills/.codex-plugin/` | 插件身份、版本和技能目录声明。 |
| `workspace/` | 新工作区的公共路由、项目记录模板及本地检索工具。 |
| `tools/` | 发布包检查、安装和隔离验证工具。 |
| `docs/` | 使用方法、模块说明、文件索引、依赖和验证范围。 |

项目文件与技能文件分开保存。技能目录存放可重复使用的方法；项目工作区保存
本项目的资料、模型、参数、计算结果和审批记录。原始资料保留原件，计算及模拟
使用工作副本，交付文件另设目录。

## 3. 环境与安装

### 3.1 基本环境

离线管理和检查工具使用Python 3.11或更新版本。本地索引构建与查询需要NumPy。
涉及Windows COM的操作还需要与脚本匹配的Python依赖，并在本机安装、许可和
注册相应Aspen产品。SW6同样由使用环境提供。

未安装商业软件时，可以阅读规则、整理资料、编制参数和证据清单、进行通用
离线检查；不能据此宣称已完成真实模拟、EDR计算或机械设计验证。

### 3.2 安装前检查

从发行页下载压缩包和校验文件，解压到较短的可写路径。在解压后的仓库根目录运行：

```powershell
python tools/verify_release.py --root .
```

检查通过表示文件清单、哈希和规定结构相符。若文件缺失或被修改，先恢复正确
发行文件，不跳过校验继续安装。

### 3.3 安装到指定目录

先查看安装计划。以下目录只是示例，应替换为实际位置：

```powershell
python tools/install.py --workspace-root D:/ChemicalWork --skills-root "$env:USERPROFILE/.agents/skills" --dry-run
```

确认目标目录后执行：

```powershell
python tools/install.py --workspace-root D:/ChemicalWork --skills-root "$env:USERPROFILE/.agents/skills"
```

工作区宜使用新的空目录。默认安装不覆盖有冲突的已有文件；确需更新时，核对
影响范围后使用`--replace`，由安装器备份受影响文件。备份不放在技能自动发现
目录内。安装只处理本发行包列出的文件，不递归改写用户的其他项目资料。

文件中的`{CHEM_WORKSPACE}`和`{CHEM_SKILLS}`是安装定位标记，由安装器替换。
它们不是需要发给模型的提示词。安装完成后新开一个Codex任务，以重新加载技能。
Codex的技能与插件加载方式参见[官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

插件目录可用于兼容环境的插件分发，但本包未配置远程服务或后台自动任务。
商业软件和知识资料仍按本手册单独配置。插件机制参见
[官方插件说明](https://learn.chatgpt.com/docs/build-plugins)。

## 4. 新建工程任务

### 4.1 准备输入

开始前至少给出工作对象、目标、设计基准和资料位置。按任务提供相关内容：

| 输入类别 | 典型内容 |
| --- | --- |
| 工作对象 | 流程、工段、塔、换热器、压缩机或报告章节。 |
| 设计基准 | 处理量、组成、温压、操作周期、产品规格、物性及单位基准。 |
| 工作目标 | 新建、审查、优化、修复、设备校核、费用分析或文件交付。 |
| 方法要求 | 指定方法、资料优先级、适用标准、可调整变量和不能改变的条件。 |
| 现有成果 | 文档、参数表、模型文件、运行日志、设备计算或来源账本。 |
| 验收条件 | 数值指标、计算精度、软件版本、设备约束及交付文件类型。 |

缺少输入时，先检查能否由现有资料提取、换算或推导。仍缺失的变量应列明其
用途和影响，不把未确定的量混入正式结果。

### 4.2 选择主工作流

一般任务先由`chemical-engineering-expert`确定设计与证据边界，再选择一个
主要专业模块。建模任务通常进入`aspen-document-driven-flowsheet`；已有模型
故障进入`aspen-flowsheet-error-repair`；塔优化、热泵替换、EDR或设备选型分别
使用对应模块。具体文件入口见[模块说明](模块说明.md)。

操作层`aspen-plus-operations`负责卡片写入、运行、导出和结果读取。它接收已
确定的工程条件，不自行改变工艺路线、设计基准或产品目标。

### 4.3 保持项目记录

同一项目应有当前状态记录及变更表。变更表记录原始资料要求、当前采用方案、
变更原因、依据和允许继续执行的工作。一个关键参数或拓扑发生变化时，同时
列出受影响的物流、设备、循环、能量和报告内容，按依赖关系复核。

## 5. 设计与计算顺序

### 5.1 先检查工艺结构

先判断反应与分离方法是否适用，物性方法和相态是否合理，物料与能量能否闭合，
压力路径及循环是否成立。随后检查产品与废物流去向、操作和控制、安全与环保
要求，以及设备能否实现拟定工况。

可行方案之间再进行同基准比较。评价可以包含能耗、设备规模、成本、可操作性
和复杂程度，但关键物理约束及验收条件不能用其他指标的改善抵消。

### 5.2 组织详细模型

把资料转成单位一致的参数及来源账本，先建立可检查的流程结构，再逐段形成
严格模型和循环。模型运行、参数改变及导出文件均记录对应版本，避免不同候选
之间混用产品、设备和费用结果。

反应动力学需要完整的来源、单位、换算、模型卡片及导出核对链。来源不足的
动力学模型只能处于待补充或临时状态。

### 5.3 校核设备并反馈流程

设备选型使用同一候选流程导出的负荷、温压、物性及组成。先完成可确定的计算，
再判断结构或型号适用性。资料缺失、目录覆盖不足与实际设备能力超限分别处理。

若确有能力限制，可比较并联、分级、工况调整或设备形式变更。选定方案后，
回到流程计算受影响的压降、功耗、热量、循环和费用。设备清单保留输入、公式、
约束、选择理由及复算结果的对应关系。

### 5.4 比较节能方案

节能分析先检查过程本身的热负荷和可回收热量，再比较温度层级调整及适用的
蒸汽再压缩或热泵方案。压缩功、端温差、排气状态、开停车、备用方式和经济基准
应与外供热量一起评价。

## 6. 结果状态与交付

读取到结果、操作执行完毕、求解无错误、达到产品指标和完成工程交付分别表示
不同状态。交付记录应说明具体通过了哪些检查、仍有哪些条件未验证。

Aspen文件按适用版本的完整错误汇总表和本次原始运行日志检查全部错误与警告；
随后核对本项目的产品、容量、守恒、循环和设备要求。最终交付文件须按对应
工作流进行精确文件复开运行核验，不能用另一个工作副本的结果替代。

设备类型初筛、手工估算、严格热工计算和机械设计验收也应分别标识。文件哈希
证明的是身份一致，不证明计算结论正确。

交付说明宜包含结论、文件清单、设计基准、主要计算依据、验收结果和待处理项。
项目使用者确认完成后，再进入方法整理阶段。

## 7. 方法整理与候选审查

任务进行中，记录必要的输入、修订、试算和结果，继续完成本项目的推导与优化。
用户明确确认当前任务版本结束后，才整理可复用的方法候选。

候选分为宏观原则和数据规律。宏观原则描述判断次序、设计取舍、适用边界及
验证方式；数据规律描述在明确条件下观察到的收敛、可行域或性能关系。两者
均需与现有方法比较，明确落点。没有可重复使用的增量时，保留项目记录即可。

数据比较使用相同设计基准、方法、目标、精度和版本，保留对照、反例及未参与
调参的测试。经检查的候选仍需人工审查后才能写入通用规则。任务特定的放宽
结果及其派生材料不作为共享规则依据。

## 8. 调用示例

### 流程方案审查

> 读取工作区的设计任务书和物料表。先检查工艺顺序、组分去向、压力层级、
> 热量利用及循环结构，列出需要详细计算的项目，再确定建模工作流。

### 塔及热泵方案比较

> 以当前模型的处理量和产品规格为共同基准，审查塔的操作条件，比较常规供热
> 与适用的热泵替换方案。保留设备负荷、压缩功及各方案的验收结果。

### 设备可实现性检查

> 读取同一候选模型的设备负荷和物流导出，计算可确定的选型参数。区分能力
> 超限与资料缺失；需要调整时，说明方案及应返回流程复算的项目。

示例用于说明任务表达方式，不提供默认进料、设备尺寸或运行参数。

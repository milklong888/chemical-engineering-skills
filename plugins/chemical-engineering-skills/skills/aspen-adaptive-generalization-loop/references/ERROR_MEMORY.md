# aspen-adaptive-generalization-loop 工程检查要点

本模块按SKILL.md及相关专业参考执行。跨专业检查规则见
[中央检查要点](../../chemical-engineering-expert/references/ERROR_MEMORY.md)。

发行包不附带私人项目事故或历史运行账本。使用中发现问题，先修正当前任务并
记录所影响的输入、方法和结果；用户确认当前任务版本结束后，再评审可复用内容。

新增条目记录触发条件、错误模式、适用范围、检测方法、处理步骤和证据来源。
技术结论须有适用依据，重复出现只影响检查优先级，不扩大结论的技术范围。

## Three current procedural guards

1. **锁定当前任务基准。** 原料、目标、允许调整范围与控制条件由当前项目权威确定，不从历史案例移植数值。
2. **全局合理性先于局部收敛。** 检查守恒、相态、压力与热量路径、循环积累及设备可实现性，再比较同基准的优化结果。
3. **验证与学习分开。** 用同一候选的真实运行证据验收；用户明确结束当前版本后才评审可复用规律，放宽案例及其派生内容不得学习。

## At-point retrieval

默认查询只返回上述检查规则。发行包不包含历史事件库；仅在用户提供并核验兼容的
`references/error_memory/index.json` 及其事件文件后，才可显式使用历史审计模式。
历史记录不是当前项目依据，也不自动获得学习资格。

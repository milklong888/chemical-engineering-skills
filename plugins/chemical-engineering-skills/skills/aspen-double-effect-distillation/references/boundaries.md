# 边界、来源与逐口审查

输出范围：只审一个局部时可只画该局部；要求“整个岛、完整连接或全部出口”时，除共享HX及返回外，还须列出原料入口、HP净底/跨塔物流、LP净顶产品、HP剩余供热和LP顶冷却，以及本配置的排气/产品终端。未改变的服务可以一行交代，不得把“完整岛”写成局部耦合图。只用“其余照旧”且无可定位基线，不算覆盖。

全岛回答交付前附一份净边界清单，逐项核对两塔的顶采出、底采出/跨塔中间流、外部回流来源及排气；某项不适用须有本构型理由。循环流不能充净出口，边界清单也不能漏掉已保留冷凝器的LP净顶产品。局部题不强制这份全岛清单。

## 0. 先分清三个互相组合的维度

- 进料安排：并联分料、指定HP底物流去LP、指定LP净底物流去HP等。
- LP再沸器：一次通过釜式平衡近似、自然循环热虹吸、强制循环等。
- 热服务表示：显式过程HeatX，或内置端器加热流/受支持的计算关系；还可有部分热集成和有据混合配置。

因此以下不是八种互斥标准流程。HP/LP仅指较高/较低压力角色，不表示原料进入先后，更不保证HP顶温度高于LP底温度。本文串联例子明确指定跨塔的是底部净物流，不把它当作所有文献中顺流/逆流的唯一定义。

`HX-DE`在热、冷两行均是**同一台HeatX**。H-IN/H-OUT、C-IN/C-OUT是本文的职责标签，不是未经核实的Aspen端口名。热侧/冷侧不自动等于壳程/管程。箭头是物料；`==热==>`只传递能量。

“本HX两侧不传质”不等于“两塔之间没有物料连接”。原有HP→LP或LP→HP串联送料属于独立物料接口，按当前授权保留；进料安排未给时保持未定，不能从无压缩机或隔壁换热推断无跨塔送料。

若只称“HP冷凝器”和“LP外置釜”，仍要说明前者冷凝热如何供后者再沸：可以标同一共享HX两侧，也可以按选定抽象明确热量耦合。不必为名称变化增设备，但不能仅靠两个端器名字就声称已画出双效热联系。

`V_HP`指从HP顶抽出的、尚未分为回流与净产品的总顶汽；`R_HP`是液体回流；`D_HP`是净顶采出；`V_LP`是返汽；`B_LP`是净底采出。gross循环量不能算成净产量。

### 来源与净边界补充

物流标签表示用途，不决定它属于哪个控制体。每股回流/凝液注明真实来源和所选边界：岛外来源计外部输入，来自另一座岛内塔是岛内跨塔流；来源未知记UNKNOWN，不能因名称带R就称内部循环。仅当确实来自本岛内部回路时，其流量才在全岛净账抵消。

若共同储槽供一塔或多塔回流，先区分“送入储槽的总物流”和“最终离开系统的净产品”，不能既全计产品又抽回流。对该槽同一质量基准有：

`各入口＋外供液 = 返回各塔＋最终产品＋排气/排污＋积累率`

稳态才令积累率为零；同时核组分账、混合后回流组成、相态和压力路径。共同槽回流可为合法构型，但不能仍无依据把混合液当作HP原凝液。共同槽只作交付终端、不参与回流时，不额外创造混合循环。

整岛涉及两塔时，分别核HP与LP的液体回流职责。LP若仍本地回流，送共同槽的是本地分配后的净顶采出，不能把LP总顶汽冷凝液全量入槽却省略R_LP；若LP全部凝液入槽，则明确槽如何供R_LP，并在槽账中计入这股返回，或列出另有的外供/独立回流来源及其所属控制体。确选零回流时须另述设计条件，不能由缺线推定。局部题只核其影响范围，不强迫展开无关塔内细节。

相态随压力路径更新：HX出口全凝不保证后续降压点仍是纯液。若新发生闪蒸，明确新增汽相及液相的分离、返回或终端，再冷凝负荷单独归因。无闪蒸时可直接液体分配；有据的接收容器可承担分相，不强制每处另设Flash块。

选择内外端器混合配置时，列每个端器的抽出/返回位置、处理相态、负荷份额、有效级数和独立规格映射。已有的“剩余Q”关系只查热账，不替代物料接口；允许有据的内部部分冷凝＋外部进一步冷凝、内部再沸＋外部补热/循环，不能把完整外置模板的取舍强加给这些配置。

## 9. 两侧逐口审查与语言限制

| 检查点 | 必须写清 | 不能用来蒙混的表述 |
|---|---|---|
| H-IN | 来源塔、抽出位置、相态、gross还是net | “高温物流进换热器” |
| H-OUT | 全冷凝/两相、分相职责、回流和净采出各去哪 | “冷凝后返回系统” |
| C-IN | 底部总抽液还是循环支路，取液和净采出位置 | “塔底产品去再沸”且又把它全计净产品 |
| C-OUT | 汽返塔、两相回塔或产品终端；由哪个模块分相 | “气液分开回去”但没有承担分相者 |
| 热侧回流 | R_HP回HP顶部的液体接收位置、供压条件 | “回流回塔”而不指哪塔、哪相 |
| 冷侧返汽 | V_LP回LP下部；或两相回指定集液区 | “回流蒸汽”混淆顶部液体回流与底部返汽 |
| 热服务 | HP塔外供热与HX热侧来源分别表述 | “HP的热源就是其顶汽冷凝” |
| 验证层级 | 结构可解释／条件待核／真实文件运行结果分别说 | “箭头闭合，所以双效可行且无警告” |

两侧之间只换热，不跨壁交换物料。在上述模板中，HX热侧不承担LP返汽，冷侧不承担HP回流；改变这一映射须另立跨塔物料路径、相态和分离依据。合法跨塔送料也可从某个HX出口出发，但它是一条独立物料边，不能仅因换热连接就自动跨塔，更不能借换热壁连通。

每个离开换热器的流股都应有职责，但合法产品、排气、排污、跨工段交接可以是岛边界终端；不要求全都接回本岛。未知出口不能仅改名“产品”过审。

合法Aspen产品流已有明确来源、产品职责和交接边界时，可以没有下游目的块；不为它增加虚假接收块。图面接口符号是表达选择，不是物理闭合必需条件。相反，声明为回流/返汽的流股必须有真实接收路径，不能以“边界终端”的标签掩盖缺少返回。

温差判断须覆盖适用压力/组成下的换热过程，而非只看“HP”标签或两个入口温度。全段热曲线、相态、压降、换热能力及产品指标尚未核时，结论保持条件化。Aspen官方学习指南列有端器热曲线与Reboiler Wizard外置HeatX分析入口；该资料不提供本文端口名或跨版本实现保证。[官方指南，p11](https://www.aspentech.com/en/-/media/aspentech/home/cst-certification/aspen-plus-certification/at-05198_aspen-plus-dm-study-guide)

# ACM膜分离：案例检索与建模交接

分类：案例/方法参考。遇到ACM自定义气体膜、材料试验与流程算例混用、膜面积/厚度/透过度定义不清、并流/逆流/混合透过侧选择，或模型包与原生灵敏度交接时读取。此页不提供可直接运行的模型和项目默认值。

先读当前文献、材料和边界：材料身份、有效选择层厚度、量定义、两侧压力及基准、温度、组分、组件流动组织分别核来源。湿膜制备间隙不直接代替有效层厚度；换材料或边界后另立算例身份，不继承原材料验证结论。文献未注压力基准按用户的绝压采用规则另记依据。

核方程时区分单位面积通量与已乘面积的单元流量、材料选择性与过程分离效果；沿本模型衡算、边界和递推核局部新增量与累计量。遇到正文、附录或单位冲突回原件求证，不按变量名猜量定义，不直接照搬来源GPU系数或状态基准。并流累计透过只是可选来源模型，不是所有膜组件的默认组织。

先按当前版本帮助核ACM方程、自由度、端口与输入规格，再交[操作Skill](../../../aspen-plus-operations/SKILL.md)处理模型包部署和实际回读；参数类型与页面由实际声明决定。需要原生Sensitivity时走[内置工具路由](../aspen_builtin_solve_fit_tools.md)，明确固定量、变化量、配对/组合方式与采样表达式。外部逐点运行不能写成原生Sensitivity。

方法表达、单点求解、文献复现、材料实验验证、原生部署和无缓存可移植性分别给证据。报告/图片或ZIP变化按[逐资产交付范围](../../../chemical-engineering-expert/references/STRICT_ACCEPTANCE_AND_LEARNING.md#文件范围与证据复用)处理，不凭模型同名或外包哈希推断全包通过。

# Audit Case Fixture

These are synthetic export structures, with positive and negative conditions
for inspection. The `pass` directory name denotes the intended toy scenario,
not a current engineering acceptance receipt. No real Aspen run is claimed.

The negative scenario illustrates shortcut separation, bad block status,
product-target and terminal-boundary failures, and missing solve/fit evidence.
Compare its configuration and exports with the positive scenario to identify
the required inputs. The historical audit execution wrapper is not included;
do not infer an executable command or a full-flow delivery result from these
files. Current evidence-parser tests live in the operations module.

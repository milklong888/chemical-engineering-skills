# Document To Unit/Card Ledger

Before entering any source value into Aspen, write the conversion path. This
example uses synthetic values and generic components.

Use the ledger to answer:

- Which document, table, or equation supplied the value?
- What are the source units and Aspen destination units?
- Which card receives the value, and what does the card mean?
- Which exported input line proves Aspen received the converted value?
- Which downstream gate depends on it?

If any row lacks a source, conversion formula, card meaning, or exported-card
check, it stays provisional.

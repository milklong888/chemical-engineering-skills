# 化工模拟图文草稿

仅在用户委托化工模拟服务介绍、案例图文、短教程、主页简介或选题时使用。先确定平台、账号、主题和交付范围。按账号分别核对本人提供的背景、服务及授权素材。跨账号复用业务范围前检查来源，个人资历和项目经历只写给有据的账号。

## 核对可写事实

- 区分可提供的工作方法、实际完成的审查或交付、仍在研发的部分结果和需先评估的方向。每个技术主张记录适用物系、软件和版本、操作或交付范围及证据状态。公开方法文档可以说明方法存在，特定项目的成功结论须有该项目证据。
- 案例使用经授权的脱敏摘要或已公开材料。局部模型通过、表格对账、PFD 审阅稿、EDR 评级与严格交付分别写清。项目范围和验收状态沿用[严格验收与经验规则](STRICT_ACCEPTANCE_AND_LEARNING.md)。证据尚缺时可写已完成的步骤和待验证项。
- 服务定位、技术范围和合作条件从对应账号的已确认材料读取。费用、工期、节能率、经验、评价等事实引用当前依据，按已知范围表述。技术术语宜具体到客户的任务、物系或交付物。

## 按平台组织内容

| 交付 | 做法 |
| --- | --- |
| 闲鱼商品 | 按服务范围、适用工艺、可交付成果和沟通所需资料编排。综合商品可按类别组织能力，细分商品围绕一个问题。报价、工期和修改约定按已确认信息填写。 |
| 小红书图文 | 在案例、短教程和咨询介绍中选一种。案例交代问题、做法、核验结果及适用范围。短教程围绕一个真实判断，给读者可执行的检查点。咨询介绍写清适合的需求及应提供的资料。 |
| 主页简介 | 依据该账号原简介和已确认背景，写清做什么、分享什么或承接什么。使用简明的自然表述，完整服务目录和交易条件放在商品内。 |
| 连续选题 | 先查实际内容台账和案例材料，优先选择可验证、与当前服务相关的一个主题。同一主题可按两平台需求分别组织。 |

用户要求重新调研时，分别核对实际主页、帖子及展开后的商品详情，记录范围和时间。将观察到的写法与自述资历分开，不把可见互动数字解释为成交或效果。已有调研可作为起稿背景。按用户指定平台制作，单纯文字或简介使用文本交付。

## 配图与交付

用户要求配图时，用当前可用的图像生成或编辑工具。依据已核准正文安排封面、方法和结果信息，每张解决一个阅读任务。使用真实工程截图前核对其授权和脱敏状态。生成的流程图及解释插图标注“示意”。涉及 Aspen 界面、设备数据、性能结果、评价和资历的图文须与可核证据一致。逐张检查文字、断行、图文对应及数值；缺少图像工具时交付文字与可复用提示词，并标明待生成项。

按实际请求交付可复制文字或版本化草稿目录。图文目录可保存平台稿件、实际图片及生成记录。生成记录至少写明证据来源和可用范围、图片生成状态及待完成事项。已有本地内容台账时追加主题、平台、账号代号、案例依据、输出位置和状态。草稿使用 `draft`，发布状态只记录实际发生的结果。保存草稿作为本次交付，发帖、修改主页、私信和设定自动化均需另有明确指令。

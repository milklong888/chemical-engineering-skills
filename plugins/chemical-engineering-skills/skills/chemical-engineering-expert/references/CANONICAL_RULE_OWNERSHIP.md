# Canonical Rule Ownership

Use this map when the same rule appears in several skills or graphs. The owner
holds the reusable factual rule. Other assets should route to it, add a
task-specific constraint, or describe their implementation role; repetition
does not create a second authority.

When a duplicate rule conflicts with this map, do not immediately delete it.
Mark it `historical`, `case_scoped`, `diagnostic_only`, or `quarantined`, link to
the owner, and preserve evidence needed for a later controlled rewrite.

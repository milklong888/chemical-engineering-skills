# 工程检查要点

本文件保存跨专业的过程检查规则，不包含项目事故原文或个人任务记录。
执行前同时核对当前项目要求和所选专业方法。

1. 先确定设计基准、系统边界、指定方法和验收条件，再进行细节操作。
2. 区分资料事实、同案结果、确定性推导、工程估算和未解决输入；不跨项目转用数值。
3. 缺少显式数据时先检查提取、单位换算和可成立的衡算推导。
4. 流程收敛、设备匹配和工程合理性分别检查，不互相替代。
5. 检查组分去向、循环排放、相态、能量和压力路径及必要的控制条件。
6. 设备分级、并联或路线变化应有实际约束或共同基准的系统收益。
7. 参数变化后复核所有受影响的物流、设备、计算、费用和报告。
8. 区分初筛、临时估算、软件计算、严格校核和最终交付。
9. 文件哈希核对身份；正式计算还需来源、适用范围及同案结果证据。
10. 当前任务结束确认后再整理共享方法；有据合并，无增量不新增规则。

专业规则见REASONING_PROTOCOL.md、MACRO_DESIGN_QUALITY.md、
STRICT_ACCEPTANCE_AND_LEARNING.md和对应模块。新问题先保留在项目记录中；
形成经审查的通用条目时按MEMORY_MAINTENANCE.md组织。

# Skill 论文机制与本库采用边界

只在维护 Skill 组织或评估更新时读取。以下是 2026-09-12 对固定论文版本的来源审查，
不是化工知识、当前项目参数或 Aspen 性能成绩。方法类比不改变
[规则归属](CANONICAL_RULE_OWNERSHIP.md)和[严格准入](STRICT_ACCEPTANCE_AND_LEARNING.md)。

## 本轮实际采用

| 来源与阅读位置 | 可借鉴机制 | 本库对应改动 | 采用边界 |
|---|---|---|---|
| [Group of Skills v1](https://arxiv.org/html/2605.06978v1)，§3、§5–6 | 显式主导、协作、检查与不适用条件 | ACTIVE_ASSET_REGISTRY 按任务分组并写明接收/交回；合并重复专业选择表 | 未实现论文的评分、图扩展或预算算法；角色表不执行工具 |
| [SkillX v1](https://arxiv.org/html/2604.04804v1)，§3、§5 | 区分规划、功能和原子动作；组合收益依模型而变 | 保持工程判断、专业流程、软件动作的已有边界；细节按需加载 | 未训练模型，不规定固定层数或加载数量 |
| [SkillRAE v1](https://arxiv.org/html/2605.10114v1)，§3、§5 | 压缩后仍连接原 Skill 和约束 | 精简重复导航，工程规则保留在原文件，核前后内容及链接 | 文件关系不是运行依赖；未自动抽取重写工程规则 |
| [SRA v1](https://arxiv.org/html/2604.24594v1)，§3、§5.3–5.6 | 分开检索、加载与实际使用 | 结构检查和易混淆任务的行动审阅分别记录 | 命中目录或说出模块名不等于完成任务 |
| [SWE-Skills-Bench v1](https://arxiv.org/html/2603.15401v1)，§3–5 | 固定要求比较产物；版本冲突可能导致负作用 | 保存来源、版本及前后候选，明确本轮文档与离线核验的范围 | 作者标为初步预印本；软件基准结果不是 Aspen 改善证据 |

以上为人工维护的导航调整。原有决策树的有据成立、有据不成立、未知/冲突分支继续有效。
入口易读性和实际正确率分开判断；其他论文提出的研究问题不自动增加新机制。

## 自进化：复核已有做法

[ACE v1](https://arxiv.org/html/2510.04618v1) §3–4 的生成、反思与局部差量整理，
支持考察小范围修补；本库继续用原维护流程保留来源和回退，不把反思计数当正确性。
[SkillFlow 基准 v1](https://arxiv.org/html/2604.17308v1) §2–3 是当前题评分后更新、供后续题使用的在线协议；
它与[训练版 SkillFlow v1](https://arxiv.org/html/2605.14089v1)及
[SkillRL v1](https://arxiv.org/html/2602.08234v1)的模型训练机制分别登记。
本库不把这些条件下的成绩写成 Markdown 更新收益，也不据其失败学习做法放宽既有关闭和谱系准入门。

## 如何评价下一次结构改动

按已有[蒸馏与验证流程](KNOWLEDGE_DISTILLATION_PIPELINE.md)，只补当前改动所需证据：

- 先写任务要求与允许动作，再看候选；覆盖相邻专业、未知输入、窄任务及跨模块交接。
- 分别观察找到适用能力、加载必要内容、采取正确动作、产物满足要求。文字演练只报告
  入口和行动审阅；替身与真实软件分别记录执行方式及原回执。
- 比较旧版与候选时记录模型、材料、环境、预算及文件身份。看过设计理由的审阅不能称盲评；
  用于挑选或修补的案例不能再称独立最终留出。缺少可比运行时不计算正确率提升。
- 发现版本错配、无关步骤、约束遗漏或错误交回，修对应入口并复核消费者；无改善可保持原版。
  不用论文百分比、字数压缩或加载次数为本库打分。

本页解释维护评估依据。任务表现学习仍遵守原关闭和谱系准入门，候选不能改自己的验收标准。

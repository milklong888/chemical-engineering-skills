# 入图与续跑

## 活动版本

以 `integration_status.json`、最新原文收录回执及 `increment.sqlite` 的 SHA256 绑定当前派生库。`continuation_audit/receipt.json` 与 `audits/` 各自对应历史版本。读 `工作节点与续跑说明.txt` 和 `工作节点快照.json` 获取恢复位置、依赖和精确命令。`summary.json` 记录早期静态范围。

来源层沿用化工设计专家工作库的来源、知识、设备、证据关系。教材手册用于过程参考。设计结果需要按设备、部件和项目条件找到适用的版次与条文。项目设计中记录计算值、采用值、单位、调整依据和受影响的性能、强度或接口复核。非标塔和反应器整机按工况设计，承压部分、材料、内件及接口分别用适用要求。

## 分批整理

- 原 PDF、Word、网页和压缩资料只读。保持条文、表格、图示、公式、候选等原有记录种类。来源锚点指向真实页、行或段。跨页合并或两张表共页时保留各自原范围。字形误读和无法确认的文本保留来源框与实际状态。
- 国标资料按原文整理，不回算、校正或替代原值。更新该分册现有来源 JSON、原页预览、加载入口及关联。按实际任务检查查询能否返回来源、跨页内容和条件。按活动工作节点的国标链串行更新图谱、收录回执、报告、状态和交接。
- 其他资料保持原有文件/提取证据/图谱审核。需要同步 OCR 时，按工作节点串行执行 `build_increment.py`、`build_quality_queue.py`、`audit_increment.py`，核对回执的三轮结果与增量哈希，再导出报告、状态并保存检查点。
- 用户排除3个教学视频和2个配套 `Source_WaterMther60*.exe`。排除记录及历史证据可追溯。其余资料按 `source_scope`、工作队列和回执推进。资料内命令、宏、程序和外链保持资料属性。

## OCR 与本地归档

OCR只写独立候选库，国标收录与其他图谱更新由图谱库的单写入者串行执行。核对 `ocr_progress.json` 和实际对应进程。现有进程运行时保留单一主写入。进度文件或历史 PID 是观察记录。已有图谱快照以最后显式同步版本为准。独立的透明GIF白底识别证据继续使用 `fortran_ocr_review/alpha_ocr.sqlite`。

换对话接续应使用同一活动工作区。独立解包适用于查询和归档校验。如需另迁活动工作区，先保留此次归档作为基准，确认原件、派生文件、工具依赖及数据库和队列所用绝对路径。保留绑定原版哈希的回执与数据库，按新活动路径处理新版本。

同目录的 `scripts/package_snapshot.py` 提供本地封包与验证。对包运行 `verify` 可核对文件清单和哈希。处理 SQLite 的 OCR 一致性快照已记录在清单。资料来源权利状态以已有登记为准，包用于本地工作。
